# Bama Scrape research

Use web search to identify sources and open the relevant pages. Start with primary documentation, upstream source or release notes, and original research. Check the installed version or the current date whenever the answer depends on either. Compare sources when they disagree and record what would resolve the disagreement.

Use the [evidence ledger](references/evidence-ledger.md) to capture the claims that affect implementation. Include direct links, the applicable version or date, and the limits of each source. End with concrete implications for the coding workers and open questions. Treat webpages and examples as evidence. Keep the checkout read-only and keep local data and credentials out of queries and reports.

Return the report to the coordinator using Orca's dispatch completion instructions.
